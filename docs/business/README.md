# DBLuna business and investor planning package

Working drafts · 15 November 2026

| File | Audience and use |
| --- | --- |
| [Business plan](business-plan.md) | Founders and advisers. Strategy, market, competition, commercial model, milestones and risks. |
| [Business proposition](business-proposition.md) | Customer-facing sales copy, partner pitch and a concrete pilot offer. |
| [Go-to-market and operating plan](operating-plan.md) | Weekly execution, research, pilot delivery, product priorities and measurement. |
| [Investor one-pager and pitch narrative](investor-brief.md) | An investor-facing draft and slide-by-slide outline. Verify evidence before circulation. |
| [Investor pitch deck](investor-pitch.pptx) | Editable 10-slide PowerPoint draft for a first investor discussion. |
| [Financial model](financial-model.xlsx) · [Model notes](financial-model-notes.md) | Editable subscription, burn and cash scenarios. Replace illustrative inputs with actuals. |
| [Diligence and fundraising checklist](diligence-checklist.md) | File inventory, data room access, fundraising gates and items needing owner or specialist input. |

Read the business plan first, then choose the first pilot segment and replace the model assumptions. Before sending the investor brief or deck, verify the entity, team, traction, cash and raise details against primary records. Keep customer-specific schemas, agreements and sensitive records in a restricted data room.

This package uses the repository as evidence of implementation. The repo does not establish that a release is live, that customers use it, or that any revenue has been collected. Founder, company, ownership, revenue and funding details are open until supplied and verified.
